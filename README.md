# 页历 · Pageleaf

页历是一款直连飞书的轻量 Android 日历。适合手机、平板和常亮显示屏，支持 Android 10 及以上版本。日程保存在设备的应用私有目录，月、周、日视图都从本地读取。

[查看月、周、日和订阅面板的界面设计](docs/design/README.md)

## 使用

1. 在[飞书开发者后台](https://open.feishu.cn/app)创建一个企业自建应用，为使用者开通 `calendar:calendar:readonly`（获取日历、日程及忙闲信息）和 `offline_access`（离线访问已授权数据）两项用户身份权限。在安全设置中允许刷新用户访问凭证，发布应用版本并把账户加入应用的可用范围。
2. 在页历打开「连接飞书」，在本机填写该应用的 App ID 和 App Secret。用手机确认二维码对应的飞书授权。请为自己控制的设备单独创建应用，避免将同一份应用密钥分发给其他人。
3. 新发现且可读取的日历默认显示。可在「显示日历」中关闭不想看的日历，选择保存在本机。飞书只授予忙闲权限或接口不支持的来源会显示原因。
4. 本周的红线标出当前时间。红线接近屏幕下方时，周视图会自动向下滚动，留出查看后续日程的空间。手动上下滑动会暂停跟随，点「今天」即可回到当前时段并恢复跟随。
5. 月、周、日视图会淡化过去日期的日程和今天已经结束的日程。页面底部和「显示日历」面板会同时显示上次同步的时刻和距今时间。

## 同步与隐私

应用在亮屏且位于前台时，每 40 秒启动一轮查询。回到前台、恢复网络、切换日期范围和重新打开日历时会主动同步。每分钟内更新是正常网络和少量日历下的目标，实际延迟也受飞书响应时间、限流和网络状态影响。熄屏后暂停周期查询。离线时可以查看已经缓存的范围，并看到上次成功同步的时间。

应用直接连接飞书，无需部署同步服务、配置事件推送或开放入站端口。日程数据保存在本地 SQLite，授权凭证由 Android Keystore 中的密钥加密。退出账户会清除本机授权、日历选择及缓存。公开仓库与安装包均不带应用凭证。

## 构建

需要 JDK 17、Android SDK Platform 35 和 Build Tools 35。配置 `ANDROID_HOME` 或本机的 `local.properties` 后运行：

```sh
./gradlew :app:assembleDebug
```

调试安装包位于 `app/build/outputs/apk/debug/app-debug.apk`。连接专用测试模拟器后，可使用 `:app:connectedDebugAndroidTest` 运行设备测试。
